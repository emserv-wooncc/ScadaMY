# Supported Data Source Types and Parameters

This document outlines the configuration parameters for all available data source types, based on the `DataSourceEditDwr.java` implementation. 

When configuring or saving a data source programmatically, these are the expected properties for each type.

- `xid` (String)
- `updatePeriods` (int)
- `updatePeriodType` (int)
